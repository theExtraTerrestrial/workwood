Round 25: accounts

Workwood looks after its own accounts now: Claude today, Codex next. Each one is a tile that shows the limit closest to running out. A bar shows how much is used, and a thin mark shows how far the window has run. If the bar passes the mark, you're using it faster than the clock allows.

In the window

The foot of the sidebar always shows every account in one line each. Click it to open the tiles. Time is sped up here: axius has a session working, so watch it climb, overtake its mark, fill up and count down to the reset. Each time a limit fills or clears, a small alert appears.

The meter: two shapes A recommended

Both show the same two things: how much is used, and how far the window has run.

A · Bar and mark. Fits on one line, so the same meter works in the sidebar and under the message box.
B · Two rings. The thick ring is usage, the thin one is the clock. Looks good on a tile, but it needs room, so the sidebar would show something else.

How a tile changes

Colour comes only from the limit. Motion only means something is happening: a light that runs along the bar while a session works, a pulsing mark when you're ahead of the clock. A full account stops moving and counts down.

Settings → Accounts

The same tiles, and one more for adding an account. Click it, pick a provider, and that provider's own sign-in opens in the terminal pane the dialog already has. Rename, make default, sign in again and remove sit behind ⋯.

Under the hood
  • Accounts stay in ~/.claude-profiles, as with Claudius, so both tools see the same ones. Workwood renews tokens itself, using the lock Claudius uses.
  • Usage comes from Claude's own usage endpoint, the one behind /usage. Asking costs nothing (I checked it on axius). Besides the 5-hour and weekly limits, it reports a weekly Fable-only limit and extra-usage credits. The tile shows whichever of these is closest to full.
  • The mark is simple arithmetic: time since the window started, divided by the window's length. The reset time comes with every reading.
  • Codex: each account is a CODEX_HOME folder. Its limits come with each Codex turn, so the tile says “as of your last turn”. Plans billed per use show credits instead of a bar.
