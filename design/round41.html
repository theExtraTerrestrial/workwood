What it shows

  • One constellation per project, up to six projects, each in its own part of the sky and always in the same place. Its name is written faintly beside it, like a star chart.
  • Stars are recent sessions. Newer ones are brighter; done ones leave. Lines join each star to its nearest neighbour, so a figure looks drawn, not a zigzag.
  • Moves only when something means it. The sky turns slowly and stars twinkle. A working session pulses and light runs along its figure. A finished turn sends a shooting star. A new session fades in and its line draws itself.
  • Light theme is a printed star chart: ink stars on paper.
  • Follows round 40: Motion (Always · While working · Never) and Warn at limits apply as for every background.
Under the hood
  • Why today's is broken: each line's length is a % of the width, but its angle is worked out from x in % of the width and y in % of the height, so on any non-square window the lines miss their stars. The stars are placed at random across the whole page, with no grouping.
  • New: one SVG, 1000 units high, its width set to the box's own shape, so stars stay round, lines always meet them and no figure is cut off. The Settings tile renders the same SVG from the same data, which is why it matches and moves.
  • Places: a project takes one of six slots, set as parts of the width and height and picked from hueOf(project), moving to the next free slot if that one is taken; a session's spot within its figure comes from seeded(id), kept at least a star's width from the others. Stars are placed oldest first, so a new session adds a star without moving the others. Lines are a minimum spanning tree per project.
  • The SVG is rebuilt only when the set of sessions changes. Working state, turn ends and new stars only add or remove classes, so the sky doesn't restart. Turn ends come from the existing session status events (work → idle).
  • The background stars are ~160 fixed points; a third twinkle. Everything is CSS animation, so the round-40 playback ramp and the hidden-window pause apply as they are.
