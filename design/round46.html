Under the hood
  • Rewind = undo files if asked (rewindFiles(prompt uuid), file checkpointing on every run; Edit/Write only, not shell commands), then cut the session file after the kept turn (temp file + rename). The next turn resumes plainly. Only while nothing holds the session.

  • Hand off from here (B, C): the handoff writer resumes with resumeSessionAt at the kept turn, so it reads only up to there. The old session is left whole; nothing is cut.
  • Context numbers: the size at any prompt is the usage on the reply just before it, already in the transcript.
