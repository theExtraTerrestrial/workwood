Three ways in: the arrow beside a prompt, Esc Esc (or /rewind) in the message box, and the outline. Each ends in the same menu, and every rewind ends in the same strip.
Under the hood
  • Rewind: undo files if asked (rewindFiles, file checkpointing on every run; Edit/Write only), then cut the session file after the kept turn (temp file + rename). Only while nothing holds the session.
  • Undo in the strip: the cut tail waits in a temp file until the next message or handoff.
  • Hand off from here: the handoff writer resumes with resumeSessionAt at the kept turn; the old session stays whole.
  • Esc Esc: two Escapes within half a second in an empty message box, while idle. During a turn the first Esc already stops it, as now.

Decided

  1. Esc Esc with text in the box clears the text first; the next Esc Esc opens the list.
  2. Undo file edits is on by default when the dropped turns edited files.
  3. The strip goes away at your next message.
  4. Rewind is only within the current session of a thread.
