Paths you can open

round 56 · hi-fi, for approval
A path in an answer's inline code that names a page, picture or video opens in the preview when you click it. Relative paths start in the project; full ones are used as written.

Pointing at it

At rest it looks like any other code. When you point at it, it takes the accent colour and a dotted underline, and the tip gives its full path. Code that names a script stays plain.

After a click

The file opens in the side panel and joins the session's previews, so ← → reach it. The chip it came from stays marked while it is shown.

When the file is gone

The file is checked when you click. If it is missing, the chip is struck through and the tip says so; nothing opens.
