Move a running step to the background

round 58 · built
A command or agent the turn is waiting on gets Background beside Stop. It keeps running, the agent goes on, and you can write to it at once.

Running

Background sits beside Stop, with its label. No shortcut: B already opens the side panel.

A moment later

The step says in background, and the strip above the box lists it while it runs. The agent is on its next step.

Under the hood
  • The button calls the SDK's backgroundTasks(toolUseId); the same call "Send now" makes already.
  • Only a step Claude Code runs as a task can move (Bash commands and subagents). Others show Stop alone, as now.
  • Its step returns at once with "moved to the background"; the tray, its output panel and the finished-notice work as for any background command.
