Under the hood
  • With Phone on, the service also listens on the PC's Tailscale address, and tailscale serve puts HTTPS in front (needed for Add to Home Screen, the mic and notifications). Off by default; nothing changes for the window.
  • The code carries a one-time pairing key. The phone trades it for its own long-lived key, kept in a cookie; Remove revokes it. The window's start-up token never leaves the PC.
  • Requests from the phone are accepted only for the tailnet name and only with a paired key. Previews are served through the main address, so the phone can load them.
  • WSL: Tailscale runs on Windows; the Windows window forwards the port, or WSL's mirrored networking is used. Probed before building.
  • The layout is the same app below ~700px wide: one pane at a time (list, session, sheet). No second UI to keep in step.
