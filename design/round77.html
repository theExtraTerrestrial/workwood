Under the hood
  • Shown only on the phone, only in a browser tab (not display-mode: standalone). The sheet once per phone; the strip until installed or hidden.
  • Android: Chrome's beforeinstallprompt is kept and Add calls it. Chrome fires it only after some use, so until then the sheet shows the menu path and swaps in Add when the offer arrives.
  • appinstalled switches the tab to screen 5. Settings › Finish setting up stays as it is.
